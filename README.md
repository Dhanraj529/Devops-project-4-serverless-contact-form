🚀 Serverless Contact Form Using AWS Lambda, API Gateway & DynamoDB

A fully serverless, auto-scaling, and cost-efficient contact form backend built using AWS Lambda, API Gateway, and DynamoDB.
This solution requires no servers, no EC2, and no maintenance, making it perfect for modern cloud-native applications.

📌 Features

🔥 100% Serverless Architecture

⚡ Pay-per-use – No cost when idle

📈 Automatic Scaling

🔒 Secure access using AWS IAM roles & policies

🗄️ Instant data storage using DynamoDB

🌐 Easy API integration with any frontend (HTML, React, Next.js, etc.)

🛠️ Lightweight & fast – runs only when triggered

🏗️ Architecture Overview
User Form -> API Gateway -> Lambda Function -> DynamoDB

Services Used

AWS Lambda → Executes backend logic on demand

Amazon API Gateway → Exposes REST API endpoint

Amazon DynamoDB → Stores form submissions

AWS IAM → Secures access between services
